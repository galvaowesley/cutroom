## Media skills: you choose what to download

Each component is only downloaded when chosen in cutroom-init . Generated by cutroom catalog --json .

## Skills

- cutroom-extract: PDF, DOCX, PPTX, XLSX, HTML and images to clean Markdown/JSON before the LLM reads them (tables, reading order, OCR). The base for reports built from documents.
- cutroom-diagram: Interactive, self-contained HTML diagrams: architecture, flow, sequence, data flow, ERD, timeline. Ready to publish or export as PNG/SVG.
- cutroom-math: Scripted math and code videos in Python (3Blue1Brown style): formulas, plots, 3D, code typed line by line, narration in sync and captions.
- cutroom-motion: Video and motion graphics from HTML/CSS/GSAP: explainers, launches, PR videos, animated slides, captions. Renders mp4, webm, gif.
- cutroom-voice: Local narration in many languages: Kokoro presets, voice blends and saved profiles; local voice cloning with consent (Chatterbox).
- cutroom-iso3d: Animated, interactive isometric figures that explain a concept as a machine (Anatomy) or as a single line (Hairline). SVG/HTML.
- cutroom-deck: 16:9 PDF decks in the active brand, on any subject: the message in the title and illustrations computed from the data. Also self-contained HTML.
- cutroom-graphic: Static graphics in the brand: social posts and stories, thumbnails, OG images, posters, banners, infographics, certificates. HTML rendered to PNG, JPG, PDF or SVG at platform sizes.
- cutroom-logo: Logo design from brief to production files: concepts, SVG craft, 16 px and one-color tests, presentation boards and export variants, then installed into a cutroom brand.
- cutroom-edit: Post-production toolbox on ffmpeg: trim, concat, narration and music mix with ducking, loudness, burned captions, reframe to 9:16 or 1:1, watermark, GIF, contact sheets, web compression.
